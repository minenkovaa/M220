    Section Module 7: Vector Spaces and Bases

    Objectives

    • VSB1 Determine whether a given set satisfies the definition of a vector space (or is a subspace).
      🔗
    • VSB2 Find a basis for an abstract vector space.
      🔗
    • VSB3 Translate between coordinate systems for different bases.
      🔗
    • VSB4 Find a basis for the null space of a given matrix.
      🔗
    • VSB5 Find a basis for the column space of a given matrix.
      🔗
    🔗
    For more details on this material, see Linear Algebra: An Interactive Introduction (Subspaces of \(\mathbb{R}^n\) Chapter) and Linear Algebra: An Interactive Introduction (Vector Spaces Chapter) and.
    🔗

    Subsection Vector Spaces and Subspaces (VSB1)

    Definition 59.

    A vector space over \(\mathbb{R}\) is a nonempty set \(V\) equipped with vector addition and scalar multiplication satisfying the following rules for all \(u,v,w\in V\) and \(c,d\in\mathbb{R}\text{.}\)
    🔗
    1. \(u+v\in V\) (closure)
      🔗
    2. \(\displaystyle u+v=v+u\)
      🔗
    3. \(\displaystyle (u+v)+w=u+(v+w)\)
      🔗
    4. There exists \(0\in V\) with \(u+0=u\text{.}\)
      🔗
    5. For each \(u\) there exists \(-u\) with \(u+(-u)=0\text{.}\)
      🔗
    6. \(cu\in V\) (closure)
      🔗
    7. \(\displaystyle c(u+v)=cu+cv\)
      🔗
    8. \(\displaystyle (c+d)u=cu+du\)
      🔗
    9. \(\displaystyle c(du)=(cd)u\)
      🔗
    10. \(\displaystyle 1u=u\)
      🔗
    🔗

    Remark 60.

    Useful identities that always hold in a vector space: \((-1)u=-u\text{,}\) \(0u=0\text{,}\) and \(c0=0\text{.}\)
    🔗
    🔗

    Subsubsection Common Examples of Vector Spaces

    • \(\displaystyle \mathbb{R}^n\)
      🔗
    • \(\displaystyle \mathbb{R}^{m\times n}\)
      🔗
    • The set of all real sequences
      🔗
    • The set of all real-valued functions on a fixed domain
      🔗
    • The polynomial space \(P_n\)
      🔗
    🔗

    Example 61. Showing that \(P_n\) is a Vector Space.

    Let \(p(x)=a_0+a_1x+\cdots+a_nx^n\) and \(q(x)=b_0+b_1x+\cdots+b_nx^n\text{.}\)
    🔗
    \begin{equation*} p(x)+q(x) =(a_0+b_0)+(a_1+b_1)x+\cdots+(a_n+b_n)x^n \in P_n. \end{equation*}
    For \(c\in\mathbb R\text{,}\)
    🔗
    \begin{equation*} cp(x) =(ca_0)+(ca_1)x+\cdots+(ca_n)x^n \in P_n . \end{equation*}
    The remaining vector-space properties are inherited from the real numbers. Therefore \(P_n\) is a vector space.
    🔗
    🔗

    Subsubsection Subspaces

    Definition 62.
    A subset \(H\subseteq V\) is a subspace if:
    🔗
    1. \(\displaystyle u,v\in H \Rightarrow u+v\in H\)
      🔗
    2. \(\displaystyle 0\in H\)
      🔗
    3. \(\displaystyle u\in H,\; c\in\mathbb R \Rightarrow cu\in H\)
      🔗
    🔗
    Example 63. A Subset That Is Not a Subspace.
    Let \(H=\{(a+2b,\,3a-b,\,4):a,b\in\mathbb R\} \subset \mathbb R^3.\)
    🔗
    Since the third component is always 4, the zero vector \((0,0,0)\) is not contained in \(H\text{.}\) Therefore \(H\) is not a subspace.
    🔗
    🔗
    Example 64. A Subset That Is a Subspace.
    Let \(K=\{(a+2b,\,3a-b,\,4a):a,b\in\mathbb R\}.\)
    🔗
    Closure under addition:
    🔗
    \begin{equation*} u+v= ((a+a')+2(b+b'), \,3(a+a')-(b+b'), \,4(a+a')) \in K. \end{equation*}
    Choosing \(a=b=0\) gives the zero vector. Scalar multiplication is also preserved, so \(K\) is a subspace.
    🔗
    🔗
    Remark 65.
    In \(\mathbb R^3\text{,}\) the span of one nonzero vector is a line through the origin, while the span of two non-collinear vectors is a plane through the origin.
    🔗
    🔗
    🔗

    Theorem 66. Span is a Subspace.

    Let \(v_1,\ldots,v_k\in V\text{,}\) a vector space. Then
    🔗
    \begin{equation*} \operatorname{span}\{v_1,\ldots,v_k\} \end{equation*}
    is a subspace of \(V\text{.}\)
    🔗
    🔗

    Proof.

    Let \(u,w\in \operatorname{span}\{v_1,\ldots,v_k\}.\)
    🔗
    Then there exist scalars \(a_1,\ldots,a_k\) and \(b_1,\ldots,b_k\) such that
    🔗
    \begin{equation*} u=a_1v_1+\cdots+a_kv_k, \end{equation*}
    \begin{equation*} w=b_1v_1+\cdots+b_kv_k. \end{equation*}
    Therefore
    🔗
    \begin{equation*} u+w = (a_1+b_1)v_1+\cdots+(a_k+b_k)v_k, \end{equation*}
    so \(u+w\) is also in the span.
    🔗
    If \(c\) is a scalar, then
    🔗
    \begin{equation*} cu = (ca_1)v_1+\cdots+(ca_k)v_k, \end{equation*}
    which is also in the span.
    🔗
    Finally,
    🔗
    \begin{equation*} 0 = 0v_1+\cdots+0v_k, \end{equation*}
    so the zero vector belongs to the span. Hence \(\operatorname{span}\{v_1,\ldots,v_k\}\) is a subspace of \(V\text{.}\)
    🔗
    🔗
    🔗

    Subsection Null Spaces, Column Spaces, and Linear Transforms

    Objectives

    • Understand the concepts of null space and column space.
      🔗
    • Compare these two notions.
      🔗
    • Connect them to previously learned concepts.
      🔗
    🔗
    Recall the homogeneous matrix equation \(Ax=0\text{.}\)
    🔗

    Definition 67.

    The null space of an \(m\times n\) matrix \(A\text{,}\) denoted by \(\operatorname{Null}(A)\) or \(\ker(A)\text{,}\) is the set of all vectors \(x\) satisfying \(Ax=0\text{.}\)
    🔗
    🔗

    Example 68.

    Describe the null space of
    🔗
    \begin{equation*} A= \begin{bmatrix} 1 & 2 & 5\\ 3 & 4 & 0 \end{bmatrix}. \end{equation*}
    Solve the homogeneous system \(Ax=0\text{.}\)
    🔗
    \begin{equation*} \operatorname{RREF}(A) = \begin{bmatrix} 1 & 0 & -10\\ 0 & 1 & \frac{15}{2} \end{bmatrix}. \end{equation*}
    Let \(x_3=t\text{.}\) Then
    🔗
    \begin{equation*} x_1=10t,\qquad x_2=-\frac{15}{2}t. \end{equation*}
    Hence
    🔗
    \begin{equation*} x = t \begin{bmatrix} 10\\[4pt] -15/2\\[4pt] 1 \end{bmatrix} . \end{equation*}
    Therefore
    🔗
    \begin{equation*} \operatorname{Null}(A) = \operatorname{span} \left\{ \begin{bmatrix} 10\\[4pt] -15/2\\[4pt] 1 \end{bmatrix} \right\}. \end{equation*}
    🔗
    Question: How do we check whether \(u\in\operatorname{Null}(A)\text{?}\)
    🔗
    Answer 1.
    Compute \(Au\text{.}\) If \(Au=0\text{,}\) then \(u\in\operatorname{Null}(A)\text{.}\)
    🔗
    🔗

    Theorem 69.

    The null space of an \(m\times n\) matrix \(A\) is a subspace of \(\mathbb{R}^n\text{.}\)
    🔗
    🔗

    Proof.

    To prove this, check the subspace conditions.
    🔗
    • Zero vector: \(A0=0\text{,}\) so \(0\in\operatorname{Null}(A)\text{.}\)
      🔗
      🔗
    • Closed under addition: If \(Ax=0\) and \(Ay=0\text{,}\) then
      🔗
      \begin{equation*} A(x+y)=Ax+Ay=0+0=0. \end{equation*}
      Thus \(x+y\in\operatorname{Null}(A)\text{.}\)
      🔗
      🔗
    • Closed under scalar multiplication: If \(Ax=0\) and \(c\in\mathbb{R}\text{,}\) then
      🔗
      \begin{equation*} A(cx)=c(Ax)=c(0)=0. \end{equation*}
      Hence \(cx\in\operatorname{Null}(A)\text{.}\)
      🔗
      🔗
    🔗

    Subsubsection How to Describe the Null Space

    The equation \(Ax=0\) gives an implicit description of \(\operatorname{Null}(A)\text{.}\)
    🔗
    To obtain an explicit description:
    🔗
    1. Find the RREF \(U\) of \(A\text{.}\)
      🔗
    2. Rewrite \(Ux=0\) as a linear system.
      🔗
    3. Express basic variables in terms of free variables.
      🔗
    4. Write \(x=c_1v_1+\cdots+c_pv_p\text{,}\) where \(p\) is the number of free variables.
      🔗
    Then
    🔗
    \begin{equation*} \operatorname{Null}(A) = \operatorname{span}\{v_1,\ldots,v_p\}. \end{equation*}
    If there are no free variables, then
    🔗
    \begin{equation*} \operatorname{Null}(A)=\{0\}. \end{equation*}
    The vectors \(v_1,\ldots,v_p\) obtained from this process are linearly independent.
    🔗
    🔗

    Definition 70.

    The column space of an \(m\times n\) matrix \(A=[a_1\ a_2\ \cdots\ a_n]\text{,}\) denoted \(\operatorname{Col}(A)\text{,}\) is the span of all columns of \(A\text{.}\)
    🔗
    🔗

    Theorem 71.

    The column space of an \(m\times n\) matrix is a subspace of \(\mathbb{R}^m\text{.}\)
    🔗
    🔗

    Proof.

    Using the description \(\operatorname{Col}(A)=\{Ax:x\in\mathbb{R}^n\}\text{:}\)
    🔗
    • If \(u=Ax\) and \(v=Ay\text{,}\) then \(u+v=A(x+y)\text{,}\) so \(u+v\in\operatorname{Col}(A)\text{.}\)
      🔗
    • If \(u=Ax\) and \(c\) is a scalar, then \(cu=A(cx)\text{,}\) so \(cu\in\operatorname{Col}(A)\text{.}\)
      🔗
    🔗

    Remark 72.

    \begin{equation*} \operatorname{Col}(A) = \{\,b : b=Ax \text{ for some } x\in\mathbb{R}^n\,\}. \end{equation*}
    For the linear transformation \(T(x)=Ax\text{,}\) the column space is the range of \(T\text{.}\)
    🔗
    🔗

    Example 73.

    Find the column space of
    🔗
    \begin{equation*} A= \begin{bmatrix} 1 & 3\\ 2 & 6 \end{bmatrix}. \end{equation*}
    Since the second column is a multiple of the first,
    🔗
    \begin{equation*} \operatorname{Col}(A) = \operatorname{span} \left\{ \begin{bmatrix} 1\\ 2 \end{bmatrix} \right\}. \end{equation*}
    🔗
    Question: Is a matrix with a given column space unique?
    🔗
    Answer 2.
    No. Many different matrices can have the same column space.
    🔗
    🔗
    Question: When is \(\operatorname{Col}(A)=\mathbb{R}^m\text{?}\)
    🔗
    Answer 3.
    Exactly when there is a pivot in every row of \(A\text{.}\)
    🔗
    🔗

    Subsubsection Comparison Between Null Space and Column Space

    Null Space
    🔗
    Column Space
    🔗
    1. \(\operatorname{Null}(A)\) is a subspace of \(\mathbb{R}^n\text{.}\)
      🔗
    2. It takes time to determine explicitly.
      🔗
    3. There is no obvious relationship with the entries of \(A\text{.}\)
      🔗
    4. \(v\in\operatorname{Null}(A)\) iff \(Av=0\text{.}\)
      🔗
    5. Membership is easy to check.
      🔗
    6. \(\operatorname{Null}(A)=\{0\}\) iff \(Ax=0\) has only the trivial solution.
      🔗
    7. \(\operatorname{Null}(A)=\{0\}\) iff \(x\mapsto Ax\) is one-to-one.
      🔗
    1. \(\operatorname{Col}(A)\) is a subspace of \(\mathbb{R}^m\text{.}\)
      🔗
    2. It is usually easier to identify.
      🔗
    3. Each column of \(A\) belongs to \(\operatorname{Col}(A)\text{.}\)
      🔗
    4. \(v\in\operatorname{Col}(A)\) iff \(Ax=v\) is consistent.
      🔗
    5. Membership generally requires solving a system.
      🔗
    6. \(\operatorname{Col}(A)=\mathbb{R}^m\) iff \(Ax=b\) has a solution for every \(b\text{.}\)
      🔗
    7. \(\operatorname{Col}(A)=\mathbb{R}^m\) iff \(x\mapsto Ax\) maps \(\mathbb{R}^n\) onto \(\mathbb{R}^m\text{.}\)
      🔗
    🔗

    Definition 74.

    A transformation \(T:V\to W\) is linear if:
    🔗
    1. \(T(u+v)=T(u)+T(v)\) for all \(u,v\in V\text{.}\)
      🔗
    2. \(T(cu)=cT(u)\) for all \(u\in V\) and scalars \(c\text{.}\)
      🔗
    🔗

    Example 75.

    Let \(V\) be the space of functions continuous on \([a,b]\) and continuously differentiable on \((a,b)\text{.}\) Define \(T(f)=f'\text{.}\)
    🔗
    Then
    🔗
    \begin{equation*} \ker(T) = \{\text{constant functions}\}. \end{equation*}
    🔗

    Example 76.

    Let \(V=C[a,b]\) and define \(T(f)=f(a)\text{.}\)
    🔗
    Then
    🔗
    \begin{equation*} \ker(T) = \{f\in C[a,b]:f(a)=0\}. \end{equation*}
    🔗
    🔗

    Subsubsection Linear Independence and Bases (VSB2)

    Definition 77.

    Vectors \(\{v_1,\dots,v_p\}\) are linearly independent if
    🔗
    \begin{equation*} c_1v_1+\cdots+c_pv_p=0 \Rightarrow c_1=\cdots=c_p=0. \end{equation*}
    🔗

    Definition 78.

    A set \(B=\{b_1,\dots,b_p\}\) is a basis for a subspace \(H\) if
    🔗
    • \(B\) is linearly independent.
      🔗
    • \(H=\operatorname{span}(B)\text{.}\)
      🔗
    🔗

    Subsubsection Reducing a Spanning Set to a Basis

    Algorithm 79.
    Start with a spanning set and remove any vector that is a linear combination of earlier vectors. Continue until no vector is redundant. The resulting set is a basis.
    🔗
    🔗
    Example 80. Abstract Vector Space Basis.
    Let \(V=\operatorname{span} \{(1,1,0,0),(2,1,1,0),(1,0,1,1)\} \subset \mathbb R^4.\)
    🔗
    \begin{equation*} A= \begin{bmatrix} 1 &2 &1\\ 1 &1 &0\\ 0 &1 &1\\ 0 &0 &1 \end{bmatrix}. \end{equation*}
    Row reduction shows pivots in every column, so all three vectors are linearly independent and form a basis of \(V\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsubsection Coordinate Systems and Change of Basis (VSB3)

    Definition 81.

    Let \(B=\{b_1,\dots,b_p\}\) be a basis of \(V\text{.}\) Every vector \(x\in V\) can be written uniquely as
    🔗
    \begin{equation*} x=c_1b_1+\cdots+c_pb_p. \end{equation*}
    The coefficient vector
    🔗
    \begin{equation*} [x]_B= \begin{bmatrix} c_1\\ \vdots\\ c_p \end{bmatrix} \end{equation*}
    is called the B-coordinate vector.
    🔗
    🔗
    Change of Coordinates
    🔗
    For bases \(B\) and \(C\) of the same space, there exists a unique matrix \(P_{C\leftarrow B}\) satisfying
    🔗
    \begin{equation*} [x]_C=P_{C\leftarrow B}[x]_B. \end{equation*}
    The columns of \(P_{C\leftarrow B}\) are the \(C\)-coordinates of the basis vectors in \(B\text{.}\)
    🔗

    Algorithm 82.

    1. Construct the augmented matrix \([\,C \mid B\,]\text{.}\)
      🔗
    2. Row-reduce to obtain \([\,I \mid P_{C\leftarrow B}\,]\text{.}\)
      🔗
    🔗
    🔗

    Subsection Null Space and Its Basis (VSB4)

    Definition 83.

    For an \(m\times n\) matrix \(A\text{,}\) the null space is
    🔗
    \begin{equation*} \operatorname{Null}(A) = \{x\in\mathbb R^n:Ax=0\}. \end{equation*}
    🔗

    Subsubsection How to Compute a Basis for the Null Space

    1. Compute the RREF of \(A\text{.}\)
      🔗
    2. Solve \(Ux=0\text{.}\)
      🔗
    3. Express the solution using free variables.
      🔗
    4. The vectors attached to the free variables form a basis.
      🔗
    🔗

    Example 84. Finding a Basis for a Null Space.

    \begin{equation*} A= \begin{bmatrix} 1 &2 &3 &1\\ 2 &4 &6 &2\\ 1 &1 &1 &0 \end{bmatrix}. \end{equation*}
    Row reduction gives
    🔗
    \begin{equation*} \begin{bmatrix} 1 &0 &-1 &-1\\ 0 &1 &2 &1\\ 0 &0 &0 &0 \end{bmatrix}. \end{equation*}
    Let \(x_3=s\) and \(x_4=t\text{.}\) Then
    🔗
    \begin{equation*} x= s\begin{bmatrix}1\\-2\\1\\0\end{bmatrix} + t\begin{bmatrix}1\\-1\\0\\1\end{bmatrix}. \end{equation*}
    Therefore
    🔗
    \begin{equation*} \operatorname{Null}(A) = \operatorname{span} \left\{ \begin{bmatrix}1\\-2\\1\\0\end{bmatrix}, \begin{bmatrix}1\\-1\\0\\1\end{bmatrix} \right\}. \end{equation*}
    🔗
    🔗

    Subsection Column Space and Its Basis (VSB5)

    Definition 85.

    For an \(m\times n\) matrix \(A=[a_1\ a_2\ \cdots\ a_n]\text{,}\) the column space is
    🔗
    \begin{equation*} \operatorname{Col}(A) = \operatorname{span}\{a_1,\dots,a_n\}. \end{equation*}
    🔗

    Fact 86.

    The pivot columns of \(A\text{,}\) taken from the original matrix, form a basis for \(\operatorname{Col}(A)\text{.}\)
    🔗
    🔗

    Example 87. Finding a Basis for a Column Space.

    \begin{equation*} A= \begin{bmatrix} 1 &3 &4\\ 2 &6 &8\\ -1 &-3 &-4 \end{bmatrix}. \end{equation*}
    There is a pivot in column 1 only. Therefore a basis is
    🔗
    \begin{equation*} \left\{ \begin{bmatrix} 1\\ 2\\ -1 \end{bmatrix} \right\}. \end{equation*}
    🔗

    Example 88. A Richer Example with Two Pivots.

    \begin{equation*} B= \begin{bmatrix} 1 &2 &1\\ 0 &1 &1\\ 1 &3 &2 \end{bmatrix} \rightarrow \begin{bmatrix} 1 &0 &-1\\ 0 &1 &1\\ 0 &0 &0 \end{bmatrix}. \end{equation*}
    The pivot columns are 1 and 2. Hence a basis for \(\operatorname{Col}(B)\) is
    🔗
    \begin{equation*} \left\{ \begin{bmatrix}1\\0\\1\end{bmatrix}, \begin{bmatrix}2\\1\\3\end{bmatrix} \right\}. \end{equation*}
    🔗
    🔗

    Subsection Rank, Dimension, and Quick Tests

    Definition 89.

    The rank of a matrix \(A\) is \(\dim(\operatorname{Col}(A))\text{.}\)
    🔗
    🔗

    Definition 90.

    The row space is the span of the rows of a matrix. The nonzero rows of the RREF form a basis for the row space.
    🔗
    🔗

    Fact 91.

    (Rank–Nullity Theorem)
    🔗
    \begin{equation*} \operatorname{rank}(A) + \dim(\operatorname{Null}(A)) = n. \end{equation*}
    🔗

    Example 92.

    If \(A\) is a \(5\times7\) matrix and \(\dim(\operatorname{Null}(A))=2\text{,}\) then
    🔗
    \begin{equation*} \operatorname{rank}(A)=7-2=5. \end{equation*}
    🔗

    Subsubsection Quick Checks

    • \(\operatorname{Null}(A)=\{0\}\) iff there is a pivot in every column.
      🔗
    • \(\operatorname{Col}(A)=\mathbb R^m\) iff there is a pivot in every row.
      🔗
    🔗
    🔗

    Subsection Appendix: Worked “Is It a Vector Space?” Checklist

    1. Nonempty: Find the zero vector and verify it belongs to the set.
      🔗
    2. Closure: Verify closure under addition and scalar multiplication.
      🔗
    3. Inherited rules: Associativity, commutativity, and distributivity typically follow from the real numbers when the operations are standard.
      🔗
    4. Bad cases: Watch for hidden constants that prevent the presence of the zero vector.
      🔗

    Example 93. Function Space.

    Let \(\mathcal F=\{f:\mathbb R\to\mathbb R\}\text{.}\) With pointwise operations, \((f+g)(x)=f(x)+g(x)\) and \((cf)(x)=cf(x)\text{,}\) all vector-space axioms hold.
    🔗
    🔗

    Example 94. A Set That Is Not a Subspace.

    Consider \(W=\{(x,y)\in\mathbb R^2:x-y=1\}.\)
    🔗
    Since \((0,0)\) does not satisfy the equation, the zero vector is not in \(W\text{.}\) Therefore \(W\) is not a subspace.
